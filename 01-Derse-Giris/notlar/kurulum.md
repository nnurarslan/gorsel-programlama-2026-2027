# Python + PyQt6 + Qt Designer Kurulumu

## 1. Python

Python'ı resmi Python sitesinden indirip kurun. Windows kurulumunda **Add python.exe to PATH** seçeneğini işaretleyin.

```bash
python --version
pip --version
```

## 2. PyQt6

```bash
pip install PyQt6
```

Test:

```bash
python -c "from PyQt6 import QtWidgets; print('PyQt6 hazır!')"
```

## 3. Qt Designer

Derslerde görsel arayüz tasarımı için Qt Designer kullanılacaktır. Kurulum yöntemi ders sırasında birlikte uygulanacaktır.

## 4. Kontrol

Kurulum sonunda Python, PyQt6 ve Qt Designer'ın çalıştığını doğrulayın.
